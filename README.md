### KOMPARASI ARSITEKTUR MOBILENETV3 DAN EFFICIENTNET-B2 PADA KLASIFIKASI KANKER KULIT MELANOMA DAN NON-MELANOMA
Task     : Image Classification <br>
Dataset  : ISIC 2019 (3/8 : BCC, Melanoma and SCC) <br>
Methode  : CNN (MobileNetV3-Large and EfficientNet-B2) <br>

Dataset didapatkan dari kaggle melalui link berikut ini : https://www.kaggle.com/datasets/riyaelizashaju/isic-skin-disease-image-dataset-labelled <br>
selain melalui kaggle, dataset dapat diakses melalui website resmi The International Skin Imaging Collaboration :  https://challenge.isic-archive.com/landing/2019/
